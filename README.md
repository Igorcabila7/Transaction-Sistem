#Transaction Simulation

-Simulador de transacoes bancarias

E um sistema que simula transacoes bancarias:

-Cobranca de taxas

-Operacoes de Credito e Debido

-Permite paganto mesmo quando o saldo do cliente e insuficiente acrescendo uma taxa de juros que e cobrado quando o sado do cliente for positivo
Este projecto e um exemplo do uso de Pogramacao Orientada a objectos em C#.
